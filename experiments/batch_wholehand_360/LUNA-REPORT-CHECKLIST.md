## 设计锁定与汇总边界

| 组 | 计划格数 | 预定条件 |
|---|---:|---|
| A | 100 | 固定位置、80 mm |
| B | 100 | 随机位置、80 mm |
| C | 50 | 随机位置、随机尺寸 |
| D | 50 | root 后站 2 cm，随机位置、随机尺寸 |
| 主实验 | 300 | A+B+C+D；每个计划格均保留一行真实状态 |
| 消融 | 60 | 三个预注册臂、各 20 格；每臂与 B 组预先指定的 20 格一一配对 |

- D 与 C 按预注册的相同位置、尺寸和 seed 配成 pair；只改变 root 后站 2 cm。不能移动方块或桌面抵消 root 改动。记录偏移符号和实际 root pose。
- 消融臂名称、改动定义、B20 pair IDs 在首个物理运行前锁定；不得事后改池、换 pair 或按结果挑格。若按已登记方案，分别记录 no-grip、no-wrist-servo、no-gravity-ff，并逐项证明该开关确实改变了活动控制路径。
- 主率以完整计划格为分母，同时列出进入物理 rollout 的格数和条件成功数；计划拒绝、执行错误、超时、物理失败、未启动/无法归类分别报告，互斥分类须加总回计划数。
- 主轮 master ledger 必须有 360 个预定 ID 的完整行，300 主实验与 60 消融分栏。只记录真实运行，不只保留成功格；运行错误、超时、规划拒绝和无结果格不得删除或转写成物理失败。
- 仅使用本轮锁定的 v2 门。报告 v2 门版本、源码 SHA、字段和阈值；v2 新门与历史 v5/v6 不是同一口径，不得横比、合并、补判或把旧门字段映射成 v2 成功。
- ARDY 当前只作为姿态先验；不得称为已生成完整动作或已完成 ARDY 全身闭环。逐项写清参考来源、谁输出 29 维身体动作、谁输出 7 维手指目标、腕参考修正及重力补偿（如有）。

## 视频选样与逐格视频规则

- 第一个 200 个主轮运行，无论真实结果成功或失败，都要为该格保留视频；父代理当前计划扩大为 300 主轮与 60 消融全部逐格出片。以 360 个计划 ID 建立逐格视频索引，不用一个拼接视频替代逐格原片。
- 每段从该格真实仿真状态开始伸臂时录起，持续展示真实状态与相位；成功样例覆盖闭合、抬升和保持，失败样例覆盖实际失败/超时阶段。同步保留 run ID、仿真时间、phase、结果 ID 和视频哈希。不得从动作参考或预设轨迹渲染静态姿势冒充实际状态。
- 视频展示须随样本身份绑定。物理失败只能用该失败格的视频；不能拿 no-grip 对照冒充 A/B/C/D 主组失败，也不能借用另一格、另一组或另一模型的录像。no-grip 只能作为独立标注的消融对照。
- 若某格在物理 rollout 前被规划拒绝或程序启动失败，不能伪造 rollout 视频；保留该格真实状态/日志可视化及明确的“无物理轨迹可录”标签，并将视频字段标为缺失/不适用。若运行超时且已有真实状态帧，保留到最后一帧并注明超时。
- 逐格核验 run ID、真实 scene/model/reference SHA、帧数、帧率、时长、解码结果与结果 JSON 一致。视频缺失单独记录，不改变该格物理分类或主率分母；物理成功与交付完整性分开汇报。
- 代表性选样规则在看结果前锁定：每组分别展示真实成功与失败类型；某组没有成功或失败，就明确写“本组没有观察到成功/失败格”，不从其他组借例。另提供完整逐格索引，避免代表性剪辑遮住失败。
