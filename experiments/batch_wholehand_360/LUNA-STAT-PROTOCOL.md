# 300 格抓取主实验与消融：统计及报告检查清单

用途：供主实验执行方和最终报告作者逐项核对设计、状态归类、配对和视频证据。本文件是统计审阅方案，不修改控制代码，不代表实验已运行或结果已取得。目标因果范围限于当前 MuJoCo 3.2.7 build；本轮不切换第二套引擎/版本。

## 1. 预注册设计与固定条件

| 组 | 数量 | 方块尺寸 | 方块位置 | root x | 说明 |
|---|---:|---|---|---:|---|
| A | 100 | 固定 80 mm | 固定 `(0.35, -0.18)` m | `0` m | 精确复现同一配置 |
| B | 100 | 固定 80 mm | `x ~ U[0.33,0.37]`, `y ~ U[-0.20,-0.16]` m | `0` m | 随机位置组 |
| C | 50 | `edge ~ U[70,90]` mm | 与 B 相同位置域 | `0` m | 随机位置与尺寸组 |
| D | 50 | 与 C **同一尺寸种子** | 与 C **同一位置种子/方块坐标** | `-0.02` m | 配对评估 root 后移；不移动方块或桌子抵消后移 |
| **主实验合计** | **300** | | | | |

全部主实验与消融方块质量固定 **0.12 kg**。机器人采用模型原生 **7 个右手指骨关节/链节 + 掌/腕碰撞体**；旧人工代理球 pads 的碰撞必须禁用，避免与模型手指重复接触或掩盖碰撞归属。每格记录实际 scene/model SHA、对象参数、root pose、右手指骨与掌腕 geom 列表、碰撞开关和活动 build。

消融另加 3×20=**60 格**：`nogrip`、`no_wrist_servo`、`no_gravity_ff` 各 20 格。每一臂逐项匹配 B 组预先指定的前 20 个 baseline 样本（相同方块坐标、尺寸、质量、root pose、初始 qpos、种子与参考输入）。总计划量为 360 个运行；消融不得混入主实验 300 格的分母。

## 2. 成功定义和版本口径

- 使用本次 **v2 当前基本抓取门**；把门版本号、源码 SHA、每一门的字段和阈值写进方案/结果清单，并锁定在批次开始前。
- v2 结果不得与团队历史 v5 或 v6 门数字合并、横比或重标。报告逐次列出 `result.success`、各门布尔值/数值以及终止阶段；不得只用进程返回码、视频画面、抬升高度或短暂接触替代整体成功。
- 对“整手参与物理”的验收，按活动模型中的右手指骨、掌、腕 collision geom 及实际接触对象核对；人工 pads 的碰撞必须为 off。不要将仅渲染几何、group 1 视觉副本、模型网格或可视化 hull 距离当成碰撞证据。
- 每格先判定完整实验成功：运行有权威结果、按锁定 v2 门成功、原始状态视频存在且通过逐格身份/时长/解码核验。物理成功但视频缺失仍记为物理成功，同时在“交付成功”中失败；两个字段分开报，不能用其他格的视频补位。

## 3. 分母与不确定性

### A 组：固定条件重复稳定性

A 的 100 次均为固定位置、尺寸、质量和初始设定；若 reset 无随机噪声，这 100 次是同一输入的**重复稳定性/确定性复现**检查。可报告 `100 次中成功 n 次`、逐次输出差异和失败复现率，但不得将 `n/100` 解读为随机场景泛化成功率，也不得据此使用独立 Bernoulli 假设下的二项置信区间或显著性检验。若想声称真正随机重复，需事先明确改变并记录哪些随机变量；不能事后把重复 seed 改叫随机样本。

### B/C/D 组：随机场景条件表现

分别报告每组完整计划分母（B 100、C 50、D 50），并另外报告进入物理执行的格数。`成功数/计划数` 反映整条配置到执行链的实际产出；`成功数/已执行数` 只表示“到达运行条件后”的条件成功率，必须并列展示，不能隐藏规划拒绝或预检失败。

将每个预定格归入一个互斥终态类别（总数必须回加到计划数）：

1. `success`：完成运行、v2 门全通过。
2. `planning_reject`：几何/IK/碰撞路径等规划阶段拒绝，未进入物理 rollout。
3. `execution_error`：程序、模型载入、数值异常、超时或调度错误等运行错误。
4. `physical_fail`：进入有效物理 rollout，但未满足抓取/保持等 v2 门。
5. `not_started_or_unclassified`：仍未启动或证据不足无法归类。报告截止时不可把它默认为失败或成功，应作为未决状态显式列出。

视频是独立完整性字段：`video_present_valid` / `video_missing_or_invalid`。视频缺失不能把物理失败改成规划拒绝，也不能因无视频而从计划分母剔除。失败格按实际终止状态生成该格真实 rollout 的视频；若执行前被拒绝，保留状态日志，并明确“无物理轨迹可录”，不得用静态合成画面、另一类别/格的录像或已成功格重放充作该格视频。若项目要求 300 个都交一段状态视频，则失败前的仿真状态也应由该格仿真记录生成并带标签说明它停在哪一阶段；不能把静态渲染伪称 rollout。

B/C/D 的置信区间或模型推断只能在随机化单位、抽样机制、重复/种子设计事前明确且分析考虑位置-尺寸配对后使用。若随机样本是人为选取的有限任务池，则先报有限池描述比例；不能自动套独立 Bernoulli CI。D 与 C 使用相同位置、尺寸种子且仅改变 root x，是配对对照：按 pair ID 报两边成功/失败四格和差值，不当作 100 个独立观测。C/D 只能支持 root x 偏移的当前样本内对照，且必须确认方块、桌面完全未移动。

## 4. 消融的配对分析与“参数确实生效”检查

- 事前锁定 B 的前 20 个 baseline 样本 ID。三个消融臂各自与这相同的 20 格基线一一配对；确认相同输入和不变参数后，再比较其余唯一变化。列出每个 pair 的 baseline/ablation 结果和差异，摘要包括两边成功、仅 baseline 成功、仅消融成功、两边失败。
- 对成功位报告配对四格原始计数和成功率差；如果运行完全确定、配对样本不是总体随机抽样，不要将其说成总体显著性或泛化因果。数值物理量可报逐对差值、中位数/范围及方向一致数。不要只比较两个不配对总体均值。
- `nogrip`：确认真实闭手动作/手指指令在活动控制路径被禁用；不能只改一个无效 CLI 变量。保留输入轨迹对照，并检查关节命令或 qpos 在闭合窗确实不同。
- `no_wrist_servo`：确认 wrist servo 目标力/力矩确实置零或控制分支被旁路，同时其他 arm/finger 控制保持基线；比较运行时 actuator command/torque 记录，证明该条件影响了活动 wrist。
- `no_gravity_ff`：确认重力前馈项在实际命令合成处被移除，其他反馈和轨迹保持一致；用 command trace 或逐步力矩对照确认改动生效。
- 三种消融都必须保存 before-close 的输入/状态对拍。逐项核对到闭手前的 `qpos/qvel`、参考轨迹、对象状态、root、桌、执行器命令和时间戳。若早期轨迹已经不同，需说明原因并限制因果解释；不能把相同 seed 当作“闭合前相同”的证明。
- 配对数缺失、pair ID 不一致、before-close 对拍不闭合、计划参数没有进入活动路径、模型 SHA 错配或成功字段口径不同，均标记该消融**不可解释/未验收**，不计算为已完成因果对照。不要补跑或删格来挑出预期结论。

## 5. 视频和逐格证据台账

计划表预先写入全部 300 个主实验 ID 与 60 个消融 ID。至少逐格记录：组别、pair ID、计划坐标/尺寸种子、实际坐标/尺寸/质量、root x、运行状态、终态类别、v2 success/gates、启动与结束时间、模型/scene/reference SHA、活动碰撞 geom 验证、视频路径、容器格式、分辨率、帧率、帧数、预期时长、实际时长、解码结果及视频是否与该格 raw/run identity 一致。

汇总检查：

- 主实验计划行数正好 300；A/B/C/D 分别 100/100/50/50。消融行数正好 60；每臂 20，且各与 B 前 20 个预注册 ID 匹配。
- 各组互斥终态计数之和回加到计划格数；已执行格数等于 `success + physical_fail`（若执行错误可能已进入 rollout，则单列 rollout_started 标记，避免类别定义造成错算）。
- 所有 300 个主实验格都有本格对应的实际状态视频或清楚记录视频缺失/无轨迹原因。视频缺失率按计划分母报，不能按“有视频格”报成功率。
- 成功样例由成功格原始记录生成；失败例从相应失败类型抽取并标出 ID。**若某组没有失败，不制造失败样例**，直接注明“本组没有观察到失败格”；不得用别组失败替代后暗示同组失败。
- 公开最终报告前双人复核：所有比例的分子/分母、混淆矩阵、组内总数、pair 数、视频缺失数、模型身份和手部 collision 清单。

## 6. 结论边界

主实验只能支持在本报告所列的模型、质量 `0.12 kg`、MuJoCo 3.2.7、对应配置池与 v2 门下的性能结论。D 只检验 root x 的指定小偏移；C/D 只覆盖 `[70,90] mm` 尺寸域；“方块尺寸任意”不由有限的尺寸随机样本自动推出。整手结论限于活动模型确实启用的 7 个右手指骨加掌腕 geom，不包括旧 pads 代理，不等于对手内自碰、左手或所有方向/边长都已验收。主实验负责人负责实机计划及最终对外报告；本清单不构成实机安全或效果结论。
